# DDI Codebook

This example shows how to document a small CSV file (four variables, five rows) using **DDI Codebook 2.5**.

## Example CSV input

```csv
id,gender,age,works_remote
1,M,45,1
2,F,37,0
3,F,52,1
4,M,29,0
5,M,60,1
```
* id: record identifier
* gender: coded as M / F
* age: age in years
* works_remote: 1 = usually works remotely (from home or elsewhere), 
                0 = usually works on site
